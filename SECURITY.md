# Security Policy

The OtterKeep maintainers and contributors take the security and integrity of the software very seriously. We appreciate your efforts to responsibly disclose any vulnerabilities.

---

## Supported Versions

Security updates and patches are provided for the **latest minor release series**. Older versions are not actively maintained for security patches, and users are encouraged to update to the latest release.

| Version | Supported          | Notes |
| ------- | ------------------ | ----- |
| `2.0.x` | :white_check_mark: | Active release series (Clean Architecture, Central DB, Resilient Engine) |
| `< 2.0` | :x:                | End of Life (EOL) — minimum supported version is 2.0.0 |

---

## Reporting a Vulnerability

If you discover a security vulnerability in OtterKeep, please do **NOT** open a public issue or discuss it publicly on GitHub.

### How to Report

Please report security issues via email to:

📧 **`security@eszes.me`**

### Submission Guidelines

To help us investigate and resolve the issue quickly:
* Please write your vulnerability report in **English**.
* Include a detailed description of the vulnerability and its potential impact.
* Provide step-by-step reproduction instructions, a proof of concept (PoC), or sample code.
* Specify the affected OtterKeep version, macOS version, and hardware architecture (Apple Silicon / Intel).

---

## Response and Disclosure Process

We adhere to a coordinated, responsible disclosure model:

1. **Acknowledgment (48 Hours):**  
   We will acknowledge receipt of your vulnerability report within **48 hours**.

2. **Investigation & Assessment:**  
   We will validate the issue, determine the severity and impact, and keep you informed of the progress.

3. **Resolution & Release (7 Days):**  
   We aim to develop, test, and release a security fix within **10 days** of verifying the issue.

4. **Coordinated Disclosure:**  
   We kindly ask that you keep all details regarding the reported vulnerability confidential and refrain from public disclosure until an official fix or advisory has been released. Once resolved, appropriate credit will be given in the release notes (unless you prefer to remain anonymous).

---

Thank you for helping keep OtterKeep and its users safe! 🦦
